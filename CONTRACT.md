# Meridian Wake integration contract

Vite, vanilla JS ES modules. Date 2026-09-26, model GPT-6 Astra (g6a). Own source art is procedural brick-built toy ships, tilted top-down in space. UI root owned by main agent. All gameplay exposed to UI; no framework.

## Renderer (src/scene.js, src/physics.js if needed)
Export `async createScene(container, options = {})` -> object:
- `update(dt, state, input)` -> array of events. state: `{system: {id,name,color,danger,planet}, ship: {id,name,hull,maxHull,shield,maxShield,speed,damage}, enemies: optional, paused, mode}`. input: `{thrust,turn,brake,fire,boost,aim: optional {x,y},autopilot: boolean}`.
- `setSystem(system)`, `setShip(ship)`, `setQuality('Auto'|'High'|'Balanced')`, `setPaused(bool)`, `setCombat(count, boss=false)`; enemies instantiate for requested count. Combat update emits `{type:'hit',damage}`, `{type:'kill'}`, `{type:'pickup',credits}`, `{type:'landReady',ready}`. Renderer simulates movement and enemy AI but gameplay model maintains health/credits. Need not keep previous defeated enemies unless setCombat called.
- `getTelemetry()` -> `{backend,preset,frameMs,bodies,speed,position:{x,z},enemies,landReady}`.
- `setView('title'|'flight'|'port')`, `dispose()`. `update` invoked every requestAnimationFrame, rendering internal. Normalized thrust 0..1 turn -1..1. Fire enemies/projectiles. Planet 0,0, player near planet initially. Landing can autopilot when input.autopilot true.
- Physics Rapier fixed 1/60 timestep interpolated, cleanup, preset limits. WebGPURenderer three/webgpu fallback WebGL2, TSL/node shading/postprocessing. Polished environment/celestial background, brick ship details, atmosphere, planar orbital cues, PBR/HDR/soft shadows/contact AO. No WebGL-only APIs. Opaque background.

## Game rules (src/game.js, src/content.js)
Export named `Game`, `SYSTEMS`, `SHIPS`, `OUTFITS`, `COMMODITIES`, `CAMPAIGN` (export content via game.js too). `new Game(saved?)`. `.state` serializable. `.newGame(shipId='sparrow')`, `.save()` returns JSON string, static `.load(json)` returns Game. `act(action, payload)` -> `{ok,message,...}` always; helper `.currentSystem()`, `.currentShip()`, `.availableJobs()`, `.availableStory()` and `.stats()` available. actions include `launch`, `land`, `jump` {systemId}, `acceptJob` {jobId}, `buy`/`sell` {commodityId,quantity}, `buyShip` {shipId}, `buyOutfit` {outfitId}, `payDebt` {amount}, `hireEscort`, `story` {choice}, `kill`, `damage` {amount}, `pickup` {credits}, `rescue`. State mode `port`/`flight`/`ending`/`destroyed`, systemId, shipId, credits, debt, day, fuel, hull, shield, cargo {}, outfits [], jobs [], storyIndex, log [], visited [], kills, escorts. Stats includes maxHull,maxShield,speed,damage,cargoCapacity,passengerCapacity,maxFuel and ship name/id. Can extend with discoverable named helpers. Source-derived systems and Free Worlds narrative adaptation with explicit complete story ending and ongoing sandbox. Real capacity, fuel, debt, deadlines, upgrades, boarding, fleets, mining and progression. Return clear validation feedback for all actions. Unit tests in tests/game.test.js.

Research authoritative upstream content, gather inventory source references, implement auditable catalog/import script where useful. Make provenance clear.
